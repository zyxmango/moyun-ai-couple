## 本轮发现并修复的问题

1. `SummaryRequest.date` 和 `AnniversaryUpdate.date` 的字段名遮蔽了 Python 的 `date` 类型，导致可选日期被 Pydantic 解析为只能接收 `null`。表现为指定日期生成总结返回 422，纪念日日期也无法通过修改接口更新。现已使用独立的 `DateType` 类型名，并增加两项回归测试。
2. 共同记忆和菜谱页面仍使用 Element Plus 即将废弃的单选框 `label` 取值方式。现已改为 `value`，重新构建并复查后不再产生警告。

## 未阻塞上线的技术项

- 主前端包压缩前约 1.25 MB，构建会提示大包警告。功能不受影响，但首次加载性能仍可通过路由拆包和依赖拆分改善。
- 后端测试有 16 条依赖升级提示，主要来自 Pydantic 旧式 `Config` 和 FastAPI `on_event`。当前运行正常，后续升级 Pydantic 3 或新版 FastAPI 前应迁移。
- 管理后台使用普通测试账号验证了权限隔离；没有临时提升账号为管理员，也没有执行解除情侣关系、重置密码等破坏性操作。
